# Dragon Form Storybook Illustrations

Initially created on October 8, 2026 and refined on October 9, 2026 with the built-in image_gen tool for Dragon Database. These are newly generated illustrations rather than downloaded stock artwork. No third-party stock-art license or attribution is attached to this generated set; no public-domain or copyright-free status is asserted.

The original set uses full-resolution JPEG copies at quality 92, without cropping or resizing. Its seven generated PNG originals are now also saved in [archive](archive/), along with the earlier Amphiptere focused framing variant. The warrior, ferocious, focused, encounter, fury and refinement sets use full-resolution PNG copies in this folder. Original vector illustrations, earlier JPGs and all preceding PNG artwork remain preserved. The archived originals and subsequent PNG sets are copied intact, without cropping, resizing or format conversion.
