## Typography and Licenses

**Alegreya Sans** supplies normal interface text, hero headings, and controls. **Grenze Regular 400** supplies the emblem badge caption. **DragonSlapper appears only in the preserved logo.** SVG glyphs are outlined with proportional shapes. The gallery reuses existing local Alegreya Sans files with system fallbacks.

Alegreya Sans and Grenze retain their SIL Open Font License documents: [Alegreya Sans resources](../../logos/v7/fonts/README.md) · [Grenze resources](../../logos/v6/fonts/README.md).

The restrained palette uses black ink `#101115`, steel `#C5CBD3`, matte silver `#E8EBEF`, and paper `#F4F5F7` with fine borders and muted text.

## Files and Editing

Desktop SVG frames are **1440 × 900**, with PNG exports at that size. Mobile SVG frames are **390 × 844**, with **780 × 1688** PNG exports. Each mobile version rearranges the header, hero, emblem, and dragon cards for the narrower frame.

The local gallery defaults to Explore Dragons and switches alternative/device previews, with full-size SVG links and SVG/PNG downloads. Its [SCSS](gallery.scss), [CSS](gallery.css), and [JavaScript](gallery.js) are local review resources with accessible controls, reduced-motion handling, and no remote font requests. SCSS and CSS remain manually authored siblings.

Editable SVG artwork and Python files in [source/](source/) retain the layout, colors, copy, and original illustration sources. Prior rounds, application code, logo assets, and fonts remain unchanged. No app adoption, tests, builds, or app UI checks were performed.
