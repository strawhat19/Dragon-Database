# v7 Font Files

This folder contains unmodified copies of the selected v6 font files and their SIL Open Font License 1.1 documents. It is independent of the v6 folder. Metal Mania is the chosen brand/title family for all three v7 variants; Alegreya Sans supplies body and control text.

| Exact family | Local file | Style / weight | Original source |
| --- | --- | --- | --- |
| Metal Mania | `metal-mania/MetalMania-Regular.ttf` | Regular, 400 | [Official TTF](https://raw.githubusercontent.com/google/fonts/main/ofl/metalmania/MetalMania-Regular.ttf) |
| Alegreya Sans | `alegreya-sans/AlegreyaSans-Regular.ttf` | Regular, 400 | [Official TTF](https://raw.githubusercontent.com/google/fonts/main/ofl/alegreyasans/AlegreyaSans-Regular.ttf) |
| Alegreya Sans | `alegreya-sans/AlegreyaSans-Medium.ttf` | Medium, 500 | [Official TTF](https://raw.githubusercontent.com/google/fonts/main/ofl/alegreyasans/AlegreyaSans-Medium.ttf) |
| Alegreya Sans | `alegreya-sans/AlegreyaSans-Bold.ttf` | Bold, 700 | [Official TTF](https://raw.githubusercontent.com/google/fonts/main/ofl/alegreyasans/AlegreyaSans-Bold.ttf) |

All files are static upright TrueType faces. Use Metal Mania at its real 400 weight; the supplied font does not include a bold face.

Keep the corresponding `OFL.txt` with redistributed font files. [The typography guide](../TYPOGRAPHY.md) describes their roles and opt-in usage. These resources were copied for review; no system font installation, application integration, checks, or tests were performed.
