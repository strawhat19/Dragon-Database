## Use Notes

- Grenze Black 900 or ExtraBold 800 is the recommended starting point for wordmarks and app titles. Regular 400 supplies a calmer style from the same family.
- Grenze Gotisch at weight 900 gives the strongest medieval direction. Its original variable file supports the full 100–900 range; declare that range when loading it and select 900 for heavy titles.
- Metal Mania and Pirata One each include only Regular 400. Their expressive shapes suit logos and prominent headings; use the actual 400 face rather than synthetic bold.
- Alegreya Sans 400, 500, and 700 provides the companion family for body copy, navigation, controls, and table data.
- Use the exact family names in the table when defining app font resources. The fonts can power live text; exported logo outlines preserve artwork independently of font loading.
- Keep each `OFL.txt` with redistributed font files. The full license contains the terms for embedding, redistribution, and modifications, including reserved font names where listed.

Source metadata was read to identify the files. The original font files are preserved without system installation or application adoption.
