## Palette and Typography

| Role | Color |
| --- | --- |
| Black ink | `#101115` |
| Steel | `#C5CBD3` |
| Matte silver | `#E8EBEF` |
| Paper | `#F4F5F7` |

| Muted text | `#626B77` |

**Alegreya Sans** supplies interface text, controls, and clean hero typography. **Grenze Regular 400** supplies Folio's editorial headings. **DragonSlapper appears only in the preserved logo.** SVG lettering is outlined; font shapes remain proportional. Alegreya Sans and Grenze use the retained SIL Open Font License documents: [Alegreya Sans resources](../../logos/v7/fonts/README.md) · [Grenze resources](../../logos/v6/fonts/README.md).

## Files and Editing

These are static concepts: desktop SVG frames are **1440 × 900**, with PNG exports at that size; mobile SVG frames are **390 × 844**, with **780 × 1688** PNG exports. Mobile compositions rearrange the content for the narrower frame.

The local gallery switches concept/device previews and offers full-size SVG and PNG downloads. Its manually authored [SCSS](gallery.scss), [CSS](gallery.css), and [JavaScript](gallery.js) remain review resources. It uses existing local fonts and requires no font installation or remote font requests.

Editable SVGs and Python files in [source/](source/) preserve the artwork, layout, colors, and copy. Previous mockup rounds, logo assets, fonts, and application code remain unchanged. This round makes no app adoption or implementation changes. No tests, builds, or app UI checks were run.
