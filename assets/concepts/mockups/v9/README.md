# Dragon Database — Search in Steel Mockups v9

This focused continuation of the selected Search in Steel direction keeps the full-bleed brushed-steel banner, preserved Editorial header, unchanged Classic logo, black Sign In, and Search/Browse controls inside the steel. The main hero H1 now reads **Dragon Database** in original DragonSlapper lettering: **one line on desktop**, **stacked on mobile**. The short red rule remains above the title.

## Files and Editing

Desktop SVGs and PNGs are **1440 × 900**. Mobile SVGs are **390 × 844**, with **780 × 1688** PNG exports. Outlined SVG lettering supports consistent local review.

The [gallery](index.html) keeps a single direction selector, Desktop/Mobile controls, full-size SVG links, and SVG/PNG downloads. It opens from local files with bundled interface fonts and no remote requests. Sticky review navigation, reduced-motion handling, the scroll-to-top control, and current-year Piratechs footer remain available. [SCSS](gallery.scss) and [CSS](gallery.css) are manually authored siblings; [JavaScript](gallery.js) handles local preview selection.

Editable artwork and authoring files live in [source/](source/): [01_search_in_steel.py](source/01_search_in_steel.py) authors the layouts, [03_heading_detail.py](source/03_heading_detail.py) authors the typography close-up, [banner_stage.py](source/banner_stage.py) supplies steel and edge artwork, and [lettering.py](source/lettering.py) supplies the scale and g-eye details.

Earlier rounds, application code, selected logo sources, and original fonts are preserved. This is a static review round with no app integration or publishing. No tests, builds, UI checks, or image inspection were performed.
