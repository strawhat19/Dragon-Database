## Artwork Notes

The initials and dragon artwork are custom editable paths with no font dependency. Full wordmarks remain editable Georgia text with Times New Roman and serif fallbacks. Font appearance depends on the viewer; outline the selected wordmark in a vector editor when preparing final production files.

Full logo SVGs use a transparent surrounding canvas and a `960 × 360` viewBox. Their PNG exports are `1920 × 720`. Standalone mark SVGs use the square viewBox `24 24 312 312`, with `1024 × 1024` transparent PNG exports. The comparison sheet has an opaque dark background and light presentation cards.

Each SVG contains an accessible title and description, descriptive group IDs, and editable flat color fills. PNG files share their corresponding SVG names; for example, `01-db-nightmaw-prime.png` contains the full logo and `01-db-nightmaw-prime-mark.png` contains its standalone mark.

All three prior rounds are preserved. No application assets or code were changed, no mockups were created, and no tests, builds, or application UI checks were run.
