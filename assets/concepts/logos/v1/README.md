## Artwork Notes

The individual SVGs have transparent surrounding canvases, a `960 × 360` viewBox, accessible titles and descriptions, and editable path artwork. The PNG lockups are exported at `1920 × 720`; the comparison sheet has an opaque presentation background.

Wordmarks remain editable text. Ember Index and Coiled D use an Avenir or system sans-serif stack. Winged Archive uses a Georgia serif stack. Scale Vault pairs a Baskerville or Georgia serif with a sans-serif secondary line. Font appearance depends on the viewer; outline the chosen typography in a vector editor when preparing final production files. No external font downloads or linked images are required.

The mark groups have descriptive IDs so they can be selected independently in a vector editor. Ember Index's ivory eye is an intentional fill; Coiled D's eye is transparent. Each palette can be changed directly in the SVG.

These are reviewable concepts. No earlier rounds existed, and no application assets or code were changed. There are no mockups in this round. No tests, builds, or application UI checks were run.
