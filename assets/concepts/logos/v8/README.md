# Dragon Database — DragonSlapper Sword Wordmarks v8

This round pairs the selected [v7 Swordmaw Hybrid dragon mark](../v7/01-db-swordmaw-hybrid.svg) with the original **DragonSlapper** font by **Allison James (NAL)**. The dragon, wings, DB monogram, and crossed sword geometry are unchanged. The font's original FontStruct release is saved under [assets/fonts/dragon-slapper-fontstruct/](../../../fonts/dragon-slapper-fontstruct/README.md).

## Typography and Color

Both concepts spell the name **Dragon Database** using DragonSlapper Regular. Original glyph proportions are maintained through uniform scaling and letter spacing. Each word and the horizontal sword span x = 401 to x = 918, a width of 517 source units. The Sword-T is a custom logo treatment; normal live app text uses the font's original “t.” No font binary has been modified.

The palette follows v7: black `#101115`, silver `#C5CBD3`, pale silver `#E4E7EB`, and a silver gradient beginning at `#B9C1CC`. Transparent exports omit the silver background while retaining the silver blade details.

Complete logo SVGs are 960 × 360; PNGs are 1920 × 720. Wordmarks crop to 548 × 320 and export as 1644 × 960 PNGs. The comparison sheet is 1200 × 1120. All SVGs include accessible titles/descriptions and outlined lettering. Authoring scripts in [source/](source/) keep wording, spacing, and sword shapes editable.
