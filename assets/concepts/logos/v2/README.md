## Artwork Notes

The lockups use a transparent surrounding canvas and a `960 × 360` viewBox. Their PNG exports are `1920 × 720`. The standalone marks use a square `280 × 280` viewBox, with `1024 × 1024` transparent PNG exports. The comparison sheet uses an opaque presentation background.

SVGs contain editable paths, descriptive mark IDs, accessible titles, and descriptions. Silver uses flat gray facets to keep the artwork scalable. Crimson Folio's dragon eye uses a crimson fill, Silver Spire's eye cuts are transparent, and Archive Signet uses black eye details.

Crimson Folio, Silver Spire, and Obsidian Codex retain a Georgia serif wordmark with system fallbacks. Archive Signet explores a lighter Baskerville or Georgia primary wordmark and a sans-serif secondary line. Text remains editable, and its appearance depends on installed fonts. Outline the selected typography in a vector editor when preparing final production files. Standalone marks have no font dependency.

PNG files share the SVG filenames. For example, `01-crimson-folio.png` contains the lockup and `01-crimson-folio-mark.png` contains the standalone mark.

The first round is preserved. No application assets or code were changed, no mockups were created, and no tests, builds, or application UI checks were run.
