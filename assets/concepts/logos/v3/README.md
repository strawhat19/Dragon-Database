## Artwork Notes

All four monograms use custom editable paths, so the letters in standalone marks have no font dependency. The full wordmark uses editable Georgia text with Times New Roman and serif fallbacks. Typography can vary with installed fonts; outline the selected wordmark in a vector editor when preparing final production files.

Full logo SVGs have a transparent surrounding canvas and a `960 × 360` viewBox. Their PNG exports are `1920 × 720`. Standalone mark SVGs use the square viewBox `32 32 296 296`, with `1024 × 1024` transparent PNG exports. The comparison sheet has an opaque dark presentation background and light cards.

Each SVG includes an accessible title and description, descriptive group IDs, and editable color fills. The flat silver palette keeps the marks scalable. PNG files share their corresponding SVG names; for example, `02-db-ironfang.png` contains the full logo and `02-db-ironfang-mark.png` contains its square mark.

This round shifts the earlier Winged Archive exploration toward dragon monograms. Both prior rounds are preserved. No application assets or code were changed, no mockups were created, and no tests, builds, or application UI checks were run.
